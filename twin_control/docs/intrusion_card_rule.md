# 동물 카드의 사람 침입 표시 (v11 후보, R11)

2026-10-16 · 대상: 통합 관제 탭 왼쪽 "실시간 동물 · 스마트락" 패널

## 무엇을 하나

카메라에서 사람 구역 침입 사건이 진행 중이면, 그 카메라가 맡은 동물의 카드에 표시한다.

- 이전에는 사람 사건이 어느 동물 카드에도 이어지지 않았다.
- 그래서 기린 이탈은 기린 카드에 경보가 떴지만, 레서판다 카메라의 사람 침입은 카드에 아무것도 나오지 않았다.

## 카메라 ↔ 동물 (`camera_animal.json`)

| 카메라 | 동물 카드 |
| --- | --- |
| ZOO_CAM_ELEPHANT_01 (CAM-01) | 아시아코끼리 (ele) |
| ZOO_CAM_GIRAFFE_01 (CAM-02) | 기린 (giraffe) |
| ZOO_CAM_TIGER_01 (CAM-07) | 벵갈호랑이 (tiger) |
| ZOO_CAM_REDPANDA_01 (CAM-05) | 레서판다 (panda) |

연결을 바꿀 때는 이 파일만 고치고 서버를 다시 켠다. 서버는 화면에 보내는 사건마다 `animal`을 붙인다. 동물별 상태는 `/api/state`의 `animals`에 담는다.

## 표시 규칙

| 항목 | 규칙 |
| --- | --- |
| 켜지는 조건 | 그 카메라에 사람 사건이 있고, 진행 중이고, 아직 "확인"하지 않았고, "오탐"으로 판정하지 않았음 |
| 꺼지는 조건 | 사건이 끝남(사람이 나감, 영상 반복, 관측 끊김) · 관제요원이 "확인"을 누름 · "오탐"으로 판정 |
| 모양 | 주황 테두리 + 사람 모양 + "▲ 사람 침입 관측 · CAM-05 · N건 (시각부터)" |
| 동물 이탈 경보와 구분 | 동물 이탈 경보는 빨강 테두리, 사람 침입은 주황 테두리. 색 말고 사람 모양과 문구로도 구분 |
| 둘 다일 때 | 동물 이탈 경보가 먼저다. 테두리는 빨강이고, 사람 침입 문구는 카드 안에 함께 나온다 |
| 카드 순서 | 동물 이탈 경보 → 사람 침입 → 나머지 |
| 순서 유지 | 사람 침입 표시가 꺼져도 10초 동안은 카드 순서를 유지한다. 사건이 짧게 끊겼다 다시 열릴 때 카드가 위아래로 요동치지 않게 하기 위해서다. 문구와 테두리는 바로 꺼진다 |

## 바꾸지 않은 것

- 판정·알림 규칙과 영상 분석(`twin_vision.py`), 사건 기록 방식
- 동물 이탈 경보가 켜지는 기준: 진행 중이고 오탐이 아닌 동물 사건 (확인해도 사건이 진행 중이면 계속 표시. 기존과 같음)
- 다른 4동물(반달가슴곰, 얼룩말, 미어캣, 수달)과 체온·심박·잠금 표시는 이전처럼 모의 데이터

## 확인 (I8)

| 시험 | 결과 |
| --- | --- |
| 레서판다 사람 침입 | 사건이 열린 지 몇 초 안에 레서판다 카드에 주황 표시, 카드가 기린(이탈 경보) 다음으로 올라감 |
| 사건 종료 | 문구와 테두리가 바로 꺼지고, 카드는 맨 위에 그대로 있음 (10초 유지 규칙). 10초 뒤 원래 순서로 돌아가는 것은 코드로만 확인했고 화면으로는 보지 못함 |
| 확인 버튼 | 확인한 사건은 바로 집계에서 빠짐 |
| 판정 동일성 | `twin_replay.py` 네 카메라 출력이 이전과 같음 |
