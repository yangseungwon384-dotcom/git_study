# 첫 화면 (v14 후보, R14)

2026-10-19 · 대상: 통합 관제 탭 (로그인 뒤 처음 보이는 화면)

## 피드백

첫 화면을 봤을 때 카메라에 눈길이 가지 않고, 무엇부터 눌러야 할지 모르겠다.

- 이전 배치는 위에서부터 모의 재생기 → 동물 카드 | 지도 | 오른쪽 위 작은 CCTV 4칸과 이벤트 → 타임라인·무전 순서였다.
- 실제 영상은 오른쪽 구석에 작게 있었다.
- 맨 위에는 모의 재생기의 "시나리오 시작" 버튼(파란 강조 버튼)이 가장 먼저 보였다.

## 첫 화면의 목적과 첫 행동 (I1)

| 항목 | 정한 내용 |
| --- | --- |
| 가장 먼저 볼 것 | 실제 영상 분석 카메라 4대 |
| 가장 먼저 누를 것 | 카메라 (누르면 카메라 탭에서 그 카메라 한 화면으로 크게 본다) |
| 경보 확인 | 경보가 생기면 큰 경보 화면(v13)이 저절로 떠서 따로 찾지 않아도 된다 |
| 모의 요소 | 시연·교육용으로 낮은 톤과 점선, "모의" 표시 |

오피스 질문(가장 먼저 누를 행동)에 답이 없어 "카메라 크게 보기"로 정했다.

## 배치 (I2, I3)

1. **실시간 카메라**: 탭 바로 아래, 화면 폭 전체, 파란 테두리.
   - 노트북 폭에서는 4칸 한 줄, 1180px 이하에서는 2칸씩 두 줄, 720px 이하에서는 1칸씩.
   - 제목 옆에 "▶ 카메라를 누르면 크게 봅니다"를 두고, 칸마다 "크게 보기 ›" 표시를 붙였다.
   - 누르면 카메라 탭의 그 카메라 한 화면으로 간다.
2. 동물 카드 | 지도 | 이벤트 (이전과 같음. 오른쪽 열의 작은 CCTV 칸은 위로 옮겨 없앴다)
3. **모의 재생기**: 맨 위에서 이 자리로 내렸다. "시연·교육용 · 실제 영상과 무관" 표시를 붙였다.
4. 타임라인 · 무전: "모의 관람객 수", "모의" 표시를 붙이고 점선 테두리로 바꿨다.

"이벤트 발생 시 자동 전환" 스위치는 카메라 칸 제목 줄로 옮겼다.

## 모의 표시 (I6)

v8의 규칙(채운 모양 = 실제, 점선 = 모의)을 첫 화면 패널에도 적용했다.

- 모의 재생기, 타임라인, 무전 패널: 점선 테두리, 옅은 제목, "모의" 칩
- 카메라 칸: 실제 영상이라 실선 파란 테두리

## 확인 (I8)

| 시험 | 결과 |
| --- | --- |
| 첫 화면 | 1366×768에서 탭 바로 아래 카메라 4칸이 화면 폭 가득 보임 |
| 카메라 누르기 | CAM-07을 누르면 카메라 탭에서 CAM-07 한 화면(영상 연결 1개) |
| 돌아오기 | 통합 관제로 돌아오면 카메라 4칸 다시 연결 (경보 큰 화면이 열려 있으면 그동안은 쉼, v13과 같음) |
| 화면 크기 | 1366px 4칸, 1100px 2칸, 375px 1칸, 가로 스크롤 없음 |
| 판정 | 바뀐 파일은 화면(`twin_control.html`)뿐이라 판정·서버에는 영향 없음 |

처음 보는 사람 5명에게 묻는 첫인상 시험은 하지 못했다. 사람이 해야 하는 시험이라 직접 확인해 주셔야 한다.

## 한계

- 동물 카드·지도·이벤트의 배치와 탭·강조색 정리(I4), 상단 요약(I5), 스트림 기준 문서(I7)는 선택되지 않았다.
