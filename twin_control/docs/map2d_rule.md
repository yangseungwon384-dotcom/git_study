# 2D 맵 표시 규칙과 스타일 (v8 후보, R7)

2026-10-15 · 대상: 통합 관제 탭의 GIS 트윈 맵(2D). 판정과 분석은 바꾸지 않았다.

## 1. 모의와 실제를 구분하는 규칙 (I1)

| 구분 | 무엇 | 표시 |
| --- | --- | --- |
| 실제 분석 | 실영상 카메라 4대 (CAM-01·02·05·07) | 채운 파란 카메라, 흰 테두리 |
| 실제 분석 | 진행 중인 실제 사건 (영상 분석) | 해당 카메라에 깜빡이는 빨간 원 + 건수 배지 |
| 모의 | 동물 GPS 위치 | 마커 바깥에 점선 원 |
| 모의 | 모의 카메라 (CAM-03·04·12) | 속이 빈 회색 점선 카메라 |
| 모의 | 현장 인력, 대응조 | 점선 원 안의 사람 모양 |
| 모의 | 관람객 수(Heatmap), 대피로, 출입문 상태, 시나리오 | 범례와 상단 안내 문구로 모의임을 알린다 (기존과 같음) |

원칙: **채운 모양 = 실제 분석, 점선 테두리 = 모의.** 경보는 색만으로 알리지 않고 '!' 표시나 건수 배지, 깜빡임을 함께 쓴다. 마우스를 올리면 나오는 이름에도 "(실영상)", "(모의)", "(모의 위치)"를 붙였다.

## 3. 동물·카메라 마커 (I3)

| 마커 | 모양 | 상태 |
| --- | --- | --- |
| 맹수 (호랑이, 코끼리, 반달가슴곰) | 마름모 | 테두리 파랑 = 정상, 빨강 + '!' + 깜빡임 = 경보, 회색 = 생체 센서 없음, 흰색 = 선택 |
| 주의 동물 (기린, 얼룩말) | 둥근 사각형 | 같음 |
| 일반 동물 (레서판다, 미어캣, 수달) | 원 | 같음 |
| 카메라 | 몸통 + 렌즈. 렌즈가 맡은 구역 쪽을 향함 | 파랑 = 실영상, 회색 점선 = 모의, 주황 = 신호 지연, 흰색 = 선택 |

마커 안의 글자(호, 코, 기 …)는 종 이름 첫 글자다.

## 4. 그리기 예산 (I8)

| 항목 | 기준 | 측정 (v7 → v8 후보) |
| --- | --- | --- |
| 2D 맵 한 번 그리기 (중앙값) | 1ms 이하 | 0.30ms → 0.60ms |
| 지도 요소 수 | 600개 이하 | 125개 → 466개 |
| 효과 | SVG 필터(흐림·그림자)를 쓰지 않음. 깜빡임은 경보 요소에만 | |

- 지도 요소는 처음 한 번 만들고, 그 뒤에는 색·위치 속성만 바꾼다 (v7과 같은 방식).
- 그리기 시간은 지도 요소의 `data-ms`에 최근 60번의 중앙값으로 남는다.
- 3D 전환과 2D 복귀, 지도 클릭 선택(동물·카메라·구역)은 그대로 동작한다.
- 서버 코드는 바꾸지 않아 영상 표시(v6)와 판단 AI(v7), 분석 속도에는 영향이 없다.

## 한계

- 2D 맵은 여전히 모의 배치도다. 3D(안내도 기준)와 위치가 다르다.
- 카메라 시야 부채꼴(I4), 마커 클릭 시 영상 이동(I5), 사건 겹침 정리(I6), 반응형 CSS(I7)는 선택되지 않아 하지 않았다.
