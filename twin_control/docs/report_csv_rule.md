# 모의 리포트 저장 (v23 후보, R23)

2026-10-20 · 승인 항목: I1 항목·열 정의, I2 저장 API·별도 CSV, I3 중복 방지, I4 저장 결과 안내, I5 사건 DB 분리 규칙, I6 CSV 탭에서 다시 보기, I10 검증

## 문제

코끼리 모의 시나리오가 끝나면(비상 해제) "사후 보고서 초안" 창이 뜬다. 하지만 창을 닫으면 다시 볼 방법이 없었다.

## 보고서 항목과 CSV 열 (I1)

보고서 창의 내용은 시나리오 기록(`S.journal`)을 시간순으로 나열한 것이다. 각 줄은 모의 시각과 내용이다(예: "16:58:02 비상 모드 진입, 대응조 호출"). 화면에 없는 값은 만들지 않았다.

| 열 | 뜻 |
| --- | --- |
| `run_id` | 실행 ID. 시나리오를 시작할 때마다 새로 만든다. 수동 비상 발령은 보고서를 띄울 때 만든다 |
| `saved_at` | 저장한 실제 시각 (서버 PC 시계) |
| `scenario` | "코끼리 이탈 징후 (모의)" 또는 "수동 비상 발령" |
| `title` | "사후 보고서 초안" |
| `line` | 보고서 안의 줄 번호 (1부터) |
| `sim_time` | 그 줄의 모의 시각 |
| `text` | 그 줄의 내용 |

보고서 하나가 여러 줄로 저장된다. 같은 `run_id`의 줄을 모으면 보고서 한 건이 된다.

## 저장 규칙 (I2, I3, I5)

- **파일:** `twin_data/scenario_reports.csv`
  - UTF-8 BOM이 붙어 있어 엑셀로 열어도 한글이 깨지지 않는다.
  - 한 번에 한 보고서씩 덧붙인다. 이미 저장된 줄은 다시 쓰지 않는다.
  - `=`·`+`·`-`·`@`로 시작하는 값은 앞에 `'`를 붙인다. 엑셀이 수식으로 읽지 않게 하려는 것으로, 사건 CSV와 같은 규칙이다.
- **언제:** 보고서 창이 뜰 때 한 번 저장한다(`POST /api/scenario-reports`).
- **중복 방지:** 같은 `run_id`가 이미 있으면 저장하지 않고 "이미 저장된 보고서"라고 알린다. 다시 시도를 눌러도 같다.
- **사건 DB와 분리:** 모의 보고서는 사건 DB(`events.sqlite3`), 판단 AI 요청, 실제 통계, 경보 목록 어디에도 넣지 않는다. v12의 "모의 사건은 DB·AI 요청 0건" 원칙과 같다.
- **권한:** 로그인한 계정이 이 관제 화면에서 보낸 요청만 받는다. 저장 줄 수는 최대 500, 한 줄은 최대 300자다.

## 화면 (I4, I6)

- **보고서 창:** 아래에 저장 결과가 나온다.
  - 성공: "✓ 저장됨: CSV 기록 탭 › 모의 리포트 (N줄, 시각)"
  - 이미 있음: "✓ 이미 저장된 보고서입니다"
  - 실패: "저장 실패 (이유). [다시 시도]". 실패해도 보고서 창은 그대로 보인다.
- **CSV 기록 탭:** 사건 표 아래에 **"모의 리포트"** 칸을 따로 두었다. 점선 테두리에 "◇ 모의 · 사건 기록과 별도"라고 표시한다.
  - 목록: 저장 시각, 제목, 시나리오, 줄 수, [보기]
  - [보기]: 저장된 보고서를 원래 창과 같은 모양으로 다시 연다("◇ 모의 · 저장본")
  - [모의 리포트 CSV 내려받기]: `GET /api/scenario-reports.csv`
- 오피스 질문(기존 목록에 섞을지, 따로 둘지)에 답이 없어, 실제 사건과 섞이지 않게 **따로** 두었다.

## 한계

- 이 기능을 넣기 전에 지나간 보고서는 저장된 적이 없어 되살릴 수 없다.
- 모의 시각은 시나리오 시계(예: 16:58)이고, 실제 시각은 `saved_at`이다.

## 확인 (I10, 시험 서버)

| 시험 | 결과 |
| --- | --- |
| 코끼리 모의 1회 완주 (3배속, 자동 진행) | 비상 해제 때 보고서 창과 함께 "✓ 저장됨 (12줄)"이 나옴. 파일은 BOM이 붙은 UTF-8로 머리글 1줄 + 12줄 |
| 같은 실행 ID 다시 저장 | `saved=false, duplicate=true`, 줄 늘지 않음 |
| 잘못된 요청 (실행 ID 형식 오류·빈 내용) | 400 |
| 저장 실패 (파일을 읽기 전용으로 막고 2회 완주) | 보고서 창은 그대로, "저장 실패 (HTTP 500). [다시 시도]"가 나옴 |
| 쓰기를 다시 허용하고 [다시 시도] | "✓ 저장됨 (12줄)", 파일에 실행 2건(각 12줄) |
| CSV 기록 탭 | "모의 리포트" 칸에 2건(최근 것부터), [보기]를 누르면 "◇ 모의 · 저장본" 12줄 |
| 사건 DB·AI 요청 | 시나리오 2회 전후 모두 사건 6,398건, 판단 요청 6,472건으로 같음 |
| 판정 동일성 | `twin_vision.py` v22와 같음, `twin_replay.py` 네 카메라 출력 같음 |
